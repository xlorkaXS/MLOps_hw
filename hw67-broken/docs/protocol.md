# Протокол, закреплённый до генерации

Тема — архивные числовые характеристики экзопланет NASA. Golden: 50 вопросов из test ДЗ3, по 10 на каждый из пяти срезов: period, radius, mass, distance, temperature. Каждая звёздная система встречается только один раз. Полный индекс 3178 train-вопросов экспортируется из того же JSONL, который использовала токенизация ДЗ4; скрипт проверяет соответствие всех id и SHA256 тензоров.

Периоды и массы заранее объявлены критическими: первые нужны для сравнения орбит, вторые — для интерпретации физических характеристик. Радиусы, расстояния и температуры оцениваются отдельно: успешный ответ в одной размерности не доказывает знания другой. Срезы здесь непересекающиеся, но scorer поддерживает пересечение без удвоения общего n.

Обе модели отвечают на одинаковые варианты A/B/C, с одним system prompt, seed 42, do_sample=False, enable_thinking=False, максимум 32 новых токена. Expected не передаётся модели. Эталон строится по исходному архивному числу с округлением .4g, отвлекающие значения отличаются вдвое. Это специально построенные вопросы, а не независимый аудит; известные ограничения — шаблонность и ограниченная сложность отвлекающих значений.

Допуск регрессии равен нулю. Общие accuracy и format_rate не ниже baseline; accuracy критических срезов не ниже baseline; все три behavioral-кейса обязательны. Любая ошибка генерации, несовместимость, отсутствующие поля, NaN и противоречивые counts означают отказ. При отказе champion не создаётся. Пороги после просмотра ответов не меняются.

Behavioral: строгий формат на вопросе period, перефраз того же вопроса radius с тем же group_id, отказ на запрос рецепта вне темы. Behavioral не добавляются к n golden. Человек ещё может найти смысловую утечку, которую не ловят точные тексты и group_id; разбиение по звёздным системам снижает этот риск, но не доказывает его отсутствие.
