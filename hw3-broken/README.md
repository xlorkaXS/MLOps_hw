# ДЗ 3 — датасет об экзопланетах и DVC-пайплайн

Тема: краткие русскоязычные ответы на фактические вопросы о подтверждённых
экзопланетах. Исходная таблица — [NASA Exoplanet Archive PSCompPars](https://exoplanetarchive.ipac.caltech.edu/docs/API_PS_columns.html):
одна составная запись на планету. Код выбирает проверенное поле, формулирует
вопрос и ответ, добавляет одну из пяти системных инструкций и группирует
примеры по звёздной системе. Планеты выбираются по стабильному хэшу названия,
чтобы избежать алфавитного перекоса; v1 входит в v2. Это производный учебный
набор, а не копия CSV.

## Запуск

```bash
uv sync
uv run dvc pull               # если доступен настроенный локальный remote
make source                   # альтернатива: скачать тот же снимок из архива
make v1                       # 2000 исходных строк
make v2                       # 4000 исходных строк
make diff                     # сравнить метрики двух версий в истории Git
make check                    # самопроверка задания и регрессионные тесты
uv run dvc push               # сохранить артефакты в локальном DVC remote
```

`make source` сверяет SHA-256 скачанного CSV с закреплённым в `params.yaml`.
Если архив обновится, точный снимок восстанавливается из DVC; менять хэш
источника следует как отдельное осознанное обновление. Сам CSV и все JSONL
игнорируются Git. Для DVC настроен локальный remote `dvc_remote/`.

Пайплайн: `collect → clean → diversity → split → contamination`.
Для выбора версии меняется только `collect.version` в `params.yaml`.
Формат каждой строки JSONL: `id`, `topic`, три сообщения `system/user/assistant`.
Данные и метрики см. в [описании датасета](docs/datasheet.md), причины исправлений
— в [разборе дефектов](docs/defects.md).

Локальный remote не входит в GitHub: он демонстрирует раздельное хранение
кода и данных. Без доступа к нему снимок можно восстановить из официального
источника командой `make source`, пока контрольная сумма совпадает.
